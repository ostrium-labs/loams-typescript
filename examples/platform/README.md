# platform

An opt-in, read-only example for `auth`, `admin.projects`, `admin.audit`, and `live.admin`. It requires a credential with the corresponding read permissions. The Live app listing is feature-detected and skipped on builds without Live.

```sh
LOAMS_PLATFORM_EXAMPLE=1 LOAMS_API_KEY=... npm run platform
```

House has no module in the 0.1.2 TypeScript SDK.
